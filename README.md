1. 为什么在Firefox下你的剪贴板不工作？

原因是kasmvnc是基于chromium的剪贴板协议，它支持二进制，而Firefox不支持。

解决方案：可以用selkies，它支持。当然了有其他的项目了，时间和我这个项目首次提交到GitHub时间接近，它的方案丝滑程度更高，但是对性能要求高，一般机器跑不起来，比如N100。

2. 为什么他妈的上传文件不支持拖拽到窗口直接传？

因为，这就是这个项目的缺陷啊，很多项目顶多只是做了上传到容器内的桌面，根本没做X11事件劫持以及Drag转发和网络挂载，你可以理解成Web就做不了这个事情，得本地代码参与。

3. 照你这么说，这个功能这么垃圾，那你们的产品也是垃圾咯？

能问出这个的一般脑子都有问题，但是我今天看了太多这样的言论了，我知道你只是一时兴起，没事的。我能包容你，因为我有时候也挺傻逼，哈哈哈哈哈
